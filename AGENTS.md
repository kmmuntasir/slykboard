# AGENTS.md

Entry point for non-Claude-Code coding agents (Codex, Cursor, etc.). Claude Code loads the same content automatically via `.claude/rules/`.

Read these before writing code:

1. [CLAUDE.md](CLAUDE.md) — project overview, commands, architecture summary.
2. `.claude/rules/persona.md` — role + specialization context.
3. `.claude/rules/backend-development-rules.md` — Express 5 / PostgreSQL / Drizzle conventions.
4. `.claude/rules/frontend-development-rules.md` — React 19 / Tailwind v4 / state-split conventions.
5. `.claude/rules/typescript-style-guide.md` + `.claude/rules/typescript-testing-rules.md` — code and test standards.
6. `.claude/rules/security-rules.md` — auth, authorization, sanitization invariants.
7. `.claude/rules/git-guidelines.md` — branching (`SLYK-*`), commit format, staging discipline.

These files are normative and duplicate-free — do not restate them here.
